## Question

ผู้เรียนต้องรู้อะไรก่อนแยกเข้าสาย Node.js หรือ Next.js บทพื้นฐาน JavaScript/TypeScript ร่วมกันควรมีจำนวนเท่าใด และผู้มีพื้นฐานเดิมควรข้ามส่วนนี้อย่างไร?

## Answer

สร้างคอร์สพื้นฐานร่วม JavaScript/TypeScript จำนวน 8 บทสำหรับผู้เริ่มต้น:

1. JavaScript ทำงานอย่างไรและการตั้งค่าเครื่องมือ
2. ตัวแปร ชนิดข้อมูล เงื่อนไข และ loop
3. Function, scope และ module
4. Array, object และการแปลงข้อมูล
5. Error handling และ debugging
6. Promise, `async/await` และการเรียก API
7. TypeScript: type, interface, union และ narrowing
8. โปรเจกต์ TypeScript ขนาดเล็กที่อ่าน API และจัดรูปข้อมูล

ผู้มีพื้นฐานเดิมทำแบบประเมินแล้วข้ามไปบทที่แนะนำได้ แต่บทที่ข้ามไม่ถูกนับว่าเรียนจบอัตโนมัติ เมื่อจบหรือข้ามตามคำแนะนำแล้ว ผู้เรียนเลือกต่อสาย Node.js หรือ Next.js ได้ทันทีโดยไม่มีการล็อก
